# Rewards

Overseer owns reward settings, claims, vote reservations, and queued deliveries. Players may use `!ov vote`, `claim`, `daily`, `rewards`, and `rewards progress`, depending on configuration.

Staff can list/preview named bundles and queue grants with `!ova rewards list`, `!ova rewards preview <id>`, and `!ova rewards grant <player> <id>`. Bifrost can edit supported vote links, bundle catalog, and playtime ladder. Offline grants wait for player availability.

Validate physical item IDs and back up Rewards data before editing. Removing a playtime tier does not erase historical claim records. Monitor+ can relay approved commands but does not own reward data.
