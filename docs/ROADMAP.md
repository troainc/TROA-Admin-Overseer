# Roadmap

Overseer owns staff operations, rewards, webhooks, Bifrost, and restart coordination. Cleaner+ owns cleanup; GridVault owns backups/recovery; Hangar owns hangar storage; AMP/Linux host own resource allocation.

Priorities: capability/freshness indicators; timestamped startup/incident diagnostics; grid dossiers and Cleaner+ preview integration; safe config/permission/maintenance workflows; server baselines, scoped alerts, compatibility, search, and accessibility. Remaining roadmap work includes Cleaner+ preview API, structured grid dossiers, redacted config history, scoped alerts, incident replay, and dependency mapping.
