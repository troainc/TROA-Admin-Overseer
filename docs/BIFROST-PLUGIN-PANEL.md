# Bifrost operator guide

Open the URL logged by Torch and sign in. Bootstrap the first Owner once, then create named accounts with least privilege. Secure remote access with HTTPS.

Overview shows plugin status and source-provided data. Plugin workspaces provide supported status, settings, and actions. Save/reload is delegated to owning plugins. Command console/history expose registered TROA commands with permission checks. Activity, analytics, rewards, access controls, and CPU affinity are separate pages.

For v0.8.99, Core Controller actions are state-aware: confirm Enable/Update to apply a validated selection; confirm Disable/Restore to turn it off. Cancel makes no change.

Images in README are illustrative sample-data previews, not live captures.
