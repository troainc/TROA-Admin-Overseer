# Configuration

Overseer writes XML settings to the StoragePath reported in Torch startup logs. Back up the full plugin folder before editing. Core files include:

- `TROA Admin Overseer.cfg` — global settings and module switches.
- `TROA Admin Overseer Webhooks.cfg` — optional named webhook routes.
- `TROA Admin Overseer Webserver.cfg` — Bifrost listener, bind address, port, public URL.
- `TROA Admin Overseer Core Controller.cfg` — optional affinity state/mask.
- Module-specific Rewards, Limits, Moderation, Connections, Broadcast, and Audit settings as generated by the installed build.

Preserve XML structure; write URL ampersands as `&amp;`. Keep secrets out of Git and screenshots. Run `!ova doctor`, then `!ova reload` where supported. Bifrost is not a generic filesystem editor: it saves only through supported owner-plugin methods. Some plugins apply changes on later scans or require restart.
